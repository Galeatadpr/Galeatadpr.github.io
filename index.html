Arsonists' Paradise

Unity · C# · Solo project

A 2D strategy puzzle game developed independently in Unity and C#, featuring resource management, daily events, multiple endings, and strategic decision-making. Implemented using object-oriented programming (OOP) principles.

Brackeys Game Jam 2025.1

Game jam · Unity · Team project

A 2D survival game developed in Unity and C# during a one-week game jam with a team of four, based on the theme “Nothing Can Go Wrong.” Role: Head Designer / Gameplay Programmer. I designed the core gameplay and progression systems, while also implementing basic gameplay logic and UI interactions. The game features misleading upgrades that can negatively affect the player, with progression centered around discovering and unlocking every upgrade.

Simplified Oskar Stalberg grid

Unity · C# · Tool

This project implements a simplified procedural terrain-grid generation approach inspired by the geometric techniques used by Oskar Stålberg, with the goal of producing a naturally structured, hexagon-based grid that can later be deformed into terrain.
